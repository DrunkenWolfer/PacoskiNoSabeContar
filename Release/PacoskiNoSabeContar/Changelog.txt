Addon: PacoskiNoSabeContar
Objetivo:
- Mostrar en las placas de nombre de Plater el porcentaje/valor de fuerzas enemigas que aporta cada mob en mazmorras miticas+.

Archivos creados:
- PacoskiNoSabeContar.toc
  - Interface: 120001, 120005.
  - OptionalDeps: Plater.
  - SavedVariables: PacoskiNoSabeContarDB.
  - Carga PacoskiNoSabeContar.lua.
- PacoskiNoSabeContar.lua
  - Addon funcional inicial.

Fuente de datos:
- No se copian tablas de BigWigs, LittleWigs ni MythicDungeonTools.
- Se usa la API de Blizzard C_ScenarioInfo.GetUnitCriteriaProgressValues(unit), que es la misma base que usa BigWigs para su opcion de progreso en nameplates.
- Se usa C_NamePlate.GetNamePlateForUnit(unit) para encontrar la placa visible.

Integracion con Plater:
- Si la placa tiene plateFrame.unitFrame.healthBar, el texto se parenta a ese healthBar.
- Si no existe healthBar, usa plateFrame.unitFrame.
- Como fallback final usa la placa de Blizzard.

Comportamiento:
- Escucha NAME_PLATE_UNIT_ADDED y NAME_PLATE_UNIT_REMOVED.
- Refresca al cambiar target, al entrar/cambiar de zona, eventos de escenario y eventos de Challenge Mode.
- Por defecto solo muestra en dificultad Mythic Keystone.
- /pnsc debug permite mostrar fuera de M+ para pruebas.

Comandos:
- /pnsc on: activa el addon.
- /pnsc off: desactiva el addon y limpia textos.
- /pnsc raw: alterna entre mostrar porcentaje y valor bruto.
- /pnsc debug: alterna modo debug.
- /pnsc nobw: intenta desactivar la opcion progressNameplate de BigWigs para evitar duplicados.

Ajustes visuales actuales:
- Texto anclado a RIGHT/RIGHT del parent.
- Offset x = 34, y = 0.
- Fuente STANDARD_TEXT_FONT, tamano 14, OUTLINE.
- Target: blanco opaco.
- Otros: blanco con alpha 0.75.

Correcciones realizadas:
- Se detecto que podian aparecer varios porcentajes por placa.
- Se anadio una marca interna por parent (PARENT_TEXT_KEY) para que cada healthBar de Plater tenga como maximo un texto creado por PacoskiNoSabeContar.
- Al reciclar placas, el addon limpia el texto anterior asociado al parent si pertenecia a otro unit token.
- Se anadio /pnsc nobw porque BigWigs tambien puede mostrar porcentajes en nameplates con fuente mayor y offset a la derecha, lo que puede parecer duplicado.

Notas de mantenimiento:
- No ejecutar validaciones Lua locales, segun contexto del proyecto.
- Si vuelve a haber duplicados, comprobar primero si BigWigs tiene activa su opcion de progreso en placas.
- Futuro posible: panel de opciones para posicion, tamano, formato, colores y desactivar automaticamente BigWigs solo con confirmacion del usuario.

Fix BugSack (2026-05-04):
- Corregido error "attempt to perform numeric conversion on a secret number value (execution tainted by 'PacoskiNoSabeContar')".
- Causa: calculo de width/height con GetStringWidth/GetStringHeight dentro de math.max en UpdateUnit.
- Solucion: eliminar conversion numerica y dejar frame contenedor con SetSize(1, 1), manteniendo el render del FontString.
